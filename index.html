How to print it

  1. Load a PDF on the left. Reprint splits it into a fronts file and a backs file, already in the right order for your printer.
  2. Print the fronts file. Nothing else, single-sided, and don't touch the stack when it comes out.
  3. Put that stack straight back into the paper tray, flipped over. Keep it in the order it came out.
  4. Print the backs file. Done — every sheet now has the right page on its back.
Always test with 4 sheets of scrap paper before running 200 pages. Printers differ, and one wrong setting means the whole job comes out upside down.
First time? Do the feed test — it takes one sheet

Click Download 2-page feed test and print only page 1. It comes out with a big FRONT and an arrow showing which edge went into the printer first.

Put that same sheet back in the tray, flipped the way you normally would, and print only page 2. Now look at the sheet:

  • BACK is upright and its arrow points the same way as FRONT's → choose Long edge.
  • BACK is upside down → choose Short edge.

For the order setting: print a 4-page document's fronts, re-feed, print the backs, and see whether page 2 landed behind page 1. If it landed behind page 3 instead, switch the order setting. You only ever do this once.

Why does an odd number of pages still work?

A 7-page document needs 4 sheets, and the back of the last sheet is blank. Reprint adds that blank page for you, so the fronts and backs files always have the same number of pages and the stack can never drift out of alignment.

What if my printer already does double-sided?

Then use it — you don't need this mode. Manual duplex is for single-sided printers, and for the times a duplex unit refuses a paper type it doesn't like, such as thick stock, labels or letterhead.
